# NASA Comparison Artifacts

Generated by `scripts/compare_nasa_reference.py`.

- `report.json`: machine-readable summary, provenance diagnostics, and RMS metrics.
- `metrics.csv`: one row per reported RMS/unavailable metric.
- `*_station.csv`: normalized station-wise reference/Python diffs.
- `*_r_by_x.csv`: wall-radius diffs on a common `X/R*` grid.

The report uses a historical fixture overlay track. It does not claim
that the visible NASA/JHU source generated the checked-in TT' fixture.
