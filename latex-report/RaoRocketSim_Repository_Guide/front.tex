\noindent\textbf{What this document is.} A map of the repository ordered by the data flow of the current command line. Each chapter follows one stage of a run from the entry point to the written outputs, quotes the design intent recorded in the code headers, and points to the documents under \code{docs/} that govern it. Later chapters show the current builds, report the test run, and list what is still to be done and why.
\par\medskip
\noindent\textbf{How to read it.} Chapters~1 and~2 give the orientation and the dispatch path. Chapters~3 to~9 follow stages S01 to S14. Chapters~10 and~11 cover the code that cuts across stages. Chapter~12 shows what the app produces today, Chapter~13 reports verification, and Chapter~14 holds the remaining-work register and the program goals.
