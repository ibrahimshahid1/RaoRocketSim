# Rice/JHU MOC Topology Map

The NASA/JHU code constructs the Rao nozzle as a set of characteristic regions
around the B-D-E topology. This map names the regions in the original code and
the Python port.

## Reference Case

The checked-in oracle is `outputs_M3.5Perf`, generated by `MOC_Grid_BDE`.
Important run values from `summary.out`:

- `R* = 1 in`
- `RWTD/R* = 1.0`
- `gamma = 1.4`
- `M_exit = 3.5`
- `ThetaB = 15.2196 deg`
- `lastKernelJ = 57`
- `L/R* = 12.5363`

## Topology

`TT'`
: Initial throat data line. Written to `TT'.out` and included at `j = 0` in
  `MOC_Grid.plt`, `TT'BF_Kernel.out`, and `UncroppedKernel.out`. The
  checked-in M3.5Perf `TT'.out` is a historical overlay with unresolved
  generator provenance; canonical parity follows the visible-source TT'
  construction, not blind fixture fitting.

`TT'BF`
: Initial kernel region marched along the throat arc through the B-F side.
  Written by `OutputFinalKernel()` to `TT'BF_Kernel.out`.

`B`
: Wall point at the converged throat expansion angle `ThetaB`. In Python,
  `MOCKernel.B` and `RaoTopology.B`.

`BD`
: Final right-running characteristic from wall point B inward toward D. In
  Python, `MOCKernel.bd` and `RaoTopology.BD`.

`D`
: Point selected on BD so that the DE integration satisfies Rao stationarity.
  In Python, `RaoTopology.D`.

`DE`
: Last left-running characteristic affecting the wall contour. Written in
  `summary.out` and as the `LRC DE` zone in `Summary.plt`. In Python,
  `RaoTopology.DE`.

`E`
: End of DE. In Python, `RaoTopology.E`.

`BFE`
: Region beyond the selected D point. Written to `BFE_Kernel.out`. This is not
  yet NASA-reference matched by the Python row march. `calc_bde_region`
  now keeps the wall-to-DE `CalcBDERegion` seed strip and builds a
  source-shaped `CalcRemainingMesh`/`CalcWallContour` overlay for comparison
  artifacts.

Wall contour
: Cropped wall streamline produced after the remaining mesh is marched and
  cropped to the requested length. Written to `wall.out`, `rao.dat`, and the
  `Wall contour` zone in `Summary.plt`.

## Routine Map

`CalcInitialThroatLine`
: Python analogue: `_make_throat_initial_line`.

`CalcRRCsAlongArc`
: Python analogue: `build_kernel` plus `_rrc_march_step`. The source dtheta
  unit processes now include special wall points, interior rows, axis closure,
  and the NASA mass-flow sign. Corrected-KL TT' can still fall back because
  the source interior equations go subsonic with that starting line.

`CalcArcWallPoint`
: Python analogue: `calc_arc_wall_point`.

`CalcInteriorMeshPoints`
: Python analogue: interior portion of `_rrc_march_step`.

`CalcAxialMeshPoint`
: Python analogue: axis closure portion of `_rrc_march_step`.

`CalcMassFlowAndThrustAlongMesh`
: Python analogue: `calc_massflow_along_rrc` for mass. Thrust is not yet a
  full row-mesh port.

`CalcMdotBD`
: Python analogue: `calc_mdot_bd_grid` / `calc_mdot_bd`.

`CalcLRCDE`
: Python analogue: `calc_lrc_de`.

`FindPointE`
: Python analogue: `find_point_e`.

`Deriv`, `RungeKutta`, `RungeKuttaFehlberg`
: Python analogues: `nasa_deriv`, `nasa_runge_kutta`; Fehlberg adaptation is
  still not a direct port.

`SetThetaB`
: Python analogue: `set_theta_b`.

`CalcBDERegion`, `CalcRemainingMesh`, `CalcWallContour`, `CropNozzleToLength`
:
  `CalcBDERegion`, `CalcRemainingMesh`, and `CalcWallContour` are represented
  by `calc_bde_region` for BFE overlay diagnostics.
  `build_source_contour_from_kernel` composes those stages into a first-class
  visible-source contour artifact. `CropNozzleToLength` is not yet canonical
  in Python. The current BVP path still constructs/export walls through the
  variational/coupled-wall machinery.
